## Scope and counting

This consolidated set contains **90 unique repository references**: 49 carried forward from the existing research register and topic follow-up, plus 41 from the three later AI-provider/agent batches. Topic indexes and commercial websites are tracked separately. Subpaths such as example environment files and skill documents are not counted as additional repositories.

This count is bounded to the known OmniIntel research supplied in the current project history and the two existing repository research documents. It does not mean every repository tagged on GitHub topic pages was inspected.

## Review-depth vocabulary

- **Inventory only:** URL retained; no meaningful source review established.
- **Metadata/README:** metadata, README, or product claims reviewed; not a source audit.
- **Selected source:** specific files inspected; not a full repository audit.
- **Deeper architecture review:** multiple implementation paths examined; still not a security certification.
- **Unverified/avoid:** claims, licensing, affiliation, supply chain, or authorization concerns block adoption.

No repository is approved for copying merely by appearing here. Detailed earlier video-learning findings remain in `RESEARCH_REGISTER.md` and `RESEARCH_TOPIC_FOLLOWUP.md`.
