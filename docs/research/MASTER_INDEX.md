## Review policy

Keep every user-supplied reference, including rejected, sparse, duplicate and unlicensed entries. Deduplicate by canonical owner/repository while retaining batch provenance. Topic pages and product websites are separate entities. README license claims are not equivalent to a verified LICENSE file. No source code or binary is copied merely because it is indexed.
