## Product-derived opportunities

- Consistent Web and Android workflows without making hosted services mandatory.
- Visible source citations, provider/model identity and privacy mode.
- Optional multi-model comparison with explicit disclosure that source content is sent to each selected provider.
- Separate synthetic media from source evidence.
- Local-first defaults and consent before remote processing.
- Dated, verified plan/credit claims; never market third-party access as unlimited based on directory claims.
